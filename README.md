# МЦКО — разборы задач

Решения с разбором задач с сайта https://demo.mcko.ru/test/ для 10 ИТ-класса.

## Сайт для учеников

https://neonco.github.io/MCKO/

Одностраничник (GitHub Pages): карточки задач с условием-картинкой, кодом решения
и кнопкой «Копировать». Клик по картинке открывает её на весь экран: колесо мыши —
зум, перетаскивание — сдвиг, двойной клик — сброс, Esc — закрыть.

## Как добавить задачу

1. Положить в папку нужного раздела файлы `taskN.png` (условие) и `taskN.py` (решение).
   Если решения пока нет — достаточно картинки, на сайте будет «решение скоро».
2. Пересобрать страницу:

   ```
   python build.py
   ```

3. Закоммитить и запушить:

   ```
   git add -A
   git commit -m "add taskN"
   git push
   ```

Pages сам пересоберёт сайт из ветки `main`.

## Структура

- `build.py` — собирает `index.html` из папок с задачами (пары `taskN.png` ↔ `taskN.py`)
- `index.html` — сгенерированная страница, руками не править
- `10 класс/` — `mcko_2025_11`, `mcko_24-25_uglublenka`, `mcko_23-24_ITclass`, `moko_k6`,
  `sstepik.org_lesson_969847`
- `7 класс/` — `moko_k6`
- `NADO ZNAT/` — шпаргалки
- новый раздел добавляется строкой в `SECTIONS` в `build.py`
